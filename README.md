# 🀄 한자 공부 노트 (8급~1급 · 3,500자)

스마트폰과 컴퓨터에서 쓰는 급수별 한자 학습 웹앱입니다.
`index.html` **한 파일만** 있으면 되고, 설치·회원가입·계정이 필요 없습니다.

- 웹에서 바로 보기: <https://hanja-note.github.io/>
- 파일로 쓰기: `index.html` 을 폰에 저장해 열거나, 컴퓨터에서 더블클릭하면 브라우저에서 바로 열립니다.

## 쓰는 법
- 폰에서 주소를 열고 브라우저 메뉴의 **홈 화면에 추가**를 하면 앱처럼 전체 화면으로 쓸 수 있습니다.
- **진도(외움 · 헷갈려요 · 오답)는 그 기기의 브라우저에만 저장**됩니다(localStorage).
  서버로 보내지 않으며, 기기를 바꾸거나 브라우저 데이터를 지우면 초기화됩니다.

## 기능
- **8급~1급 8단계, 3,500자** — 급수 탭을 눌러 단계별로 학습
- **카드** — 한자를 보고 훈·음과 예시 단어 2개 확인, 뒤집어서 보기
- **퀴즈** — 급수별 10문제, 정답·오답 확인
- **오답 노트** — 틀린 글자만 모아 다시 보기
- **효과음** — 카드 넘길 때 `사락` 종이 소리, 퀴즈 정답은 `딩동댕` 3음 · 오답은 `띵` 단음.
  오디오 파일 없이 브라우저에서 직접 합성(Web Audio)하므로 내려받는 용량 0
- **소리 켜기/끄기** — 헤더 오른쪽 `🔊`/`🔇` 버튼, 고른 상태는 그 기기에 저장
- **진행률** — 급수마다 외운 글자 수 표시, 누적 3,500자
- **획순 · 따라쓰기** — 카드 아래 `✍️ 획순 · 따라쓰기` 버튼을 누르면 아래에서 패널이 올라옵니다.
  - `▶ 획순 보기` — 1획부터 차례로 획순 애니메이션(총 획수 표시)
  - `✍️ 따라쓰기` — 연한 본보기 위에 손가락으로 한 획씩 따라 쓰면 다음 획으로 넘어가고,
    다 쓰면 `딩동댕~` 완료음(효과음이 켜져 있을 때). `🔄 다시 쓰기`로 처음부터
  - 8급 49자는 획순 자료를 파일 안에 넣어 **인터넷 없이도** 따라쓸 수 있고,
    나머지 급수는 처음 열 때 한 글자씩 받아와 기기에 저장합니다(다시 볼 땐 즉시)
  - 획순 자료가 없는 한국식 자형(敎 · 飮 · 眞 등 172자)이나 인터넷이 끊겼을 때는
    연한 본보기 + 손가락 자유 따라쓰기로 자동 전환되어 **빈 화면이 나오지 않습니다**
- 여러 음으로 읽는 글자(降 · 更 · 龜 등)는 카드에 `다른 음`으로 함께 표시

## 수록 한자 (한국어문회 배정한자 기준, 총 3,500자)

| 급수 | 이 급수만 | 누적 | 비고 |
|---|---|---|---|
| 8급 | 50자 | 50자 | |
| 7급 | 100자 | 150자 | 준7급 50 + 7급 50 |
| 6급 | 150자 | 300자 | 준6급 75 + 6급 75 |
| 5급 | 200자 | 500자 | 준5급 100 + 5급 100 |
| 4급 | 500자 | 1,000자 | 준4급 250 + 4급 250 |
| 3급 | 817자 | 1,817자 | 준3급 500 + 3급 317 |
| 2급 | 538자 | 2,355자 | |
| 1급 | 1,145자 | 3,500자 | |

- 준급수(7급Ⅱ · 6급Ⅱ …)는 해당 급수에 합쳐 8단계로 보여 줍니다.
- 급수 간 중복 0건(각 급수의 '신규 배정한자'만 수록).
- 3,462자는 예시 단어 2개, 18자는 1개, 20자는 사전에 단어가 없어(사람 이름 · 고전 전용 글자)
  카드에 설명을 대신 넣었습니다.

## 예시 단어는 어떻게 골랐나
1. **글자·훈·음**: 한국어문회 급수별 배정한자 자료(rycont/hanja-grade-dataset)에서 8급~1급 3,500자를 추출.
2. **예시 단어**: 국립국어원 **표준국어대사전**·**우리말샘**의 표제어와 한자 표기를 받아
   (표준국어대사전 32만 건, 우리말샘 82만 건) 그 글자가 실제로 들어간 단어만 골랐습니다. 지어낸 단어는 없습니다.
   - 단어의 음절 수와 한자 표기 수가 1:1로 맞는 것만 후보로 사용
   - 표준국어대사전 > 우리말샘 > Kengdic 순으로 우선, 여러 사전에 같은 표기로 실린 단어를 먼저 선택
   - 같은 한글에 다른 한자 표기가 있는 동음이의어는 뒤로 미룸
   - `~하다` 꼴 활용형은 제외
3. **사전에 단어가 없던 글자**(사람 이름 · 고전 전용 20자: 予 珏 鉀 炅 琯 玖 燉 旼 昞 昺 潽 珣 瑢 鈗 琮 炫 邢 嬅 烋 棉):
   예시 단어 대신 "주로 사람 이름에 쓰는 글자예요" 같은 설명을 넣었습니다.

## 데이터 출처
- 급수별 배정한자 목록: 한국어문회 배정한자표 공개 정리본 (rycont/hanja-grade-dataset)
- 예시 단어·훈음 대조: 국립국어원 표준국어대사전·우리말샘 (CC-BY-SA 2.0 KR), Kengdic, Yomitan 한자 사전
- 8~5급 500자의 훈음·단어: opentutorials 정리본을 어린이가 읽기 쉽게 다듬어 사용

## 개인정보 · 광고
- 이름·전화번호·이메일·계정 등 개인정보가 파일에 들어 있지 않습니다.
- 외부 광고·추적·분석 코드가 없습니다.
- **획순 자료만** 처음 볼 때 jsDelivr · unpkg(오픈소스 CDN)에서 그 글자 파일 하나(약 2~3KB)를 받아옵니다.
  서버에 남는 것은 그 글자 파일 요청뿐이며(이름·계정·기기 정보 없음), 받은 자료는 그 기기 저장소에 넣어
  두 번째부터는 요청하지 않습니다. 8급 49자는 파일에 함께 들어 있어 전혀 요청하지 않고,
  인터넷이 없어도 카드·퀴즈·오답노트는 물론 따라쓰기까지(본보기 캔버스) 그대로 동작합니다.
- 학습 기록과 받아 둔 획순 자료는 브라우저 저장소에만 남습니다.
